# End-Grain Pattern Research

Research date: 2026-06-21

## Product constraint

The current designer models one long-grain strip glue-up, crosscuts that panel into equal slices, and performs one final glue-up. Each slice can be flipped, rotated 180 degrees, or shifted across the panel width. A preset should only produce a build plan when that sequence can actually make the previewed board.

This distinction matters because many boards marketed as a single pattern use several independently built blanks, repeated rip-and-reglue operations, or individually assembled blocks. For example, the basket-weave build described by Obsessed Woodworking uses three contrasting hardwoods, multiple glue-ups, opposite-direction cuts, and rotated/flipped strips. The simpler current SawdustAtlas recipe cannot represent all of those operations faithfully.

## Pattern candidates

| Pattern | Visual recipe | Current model | Recommendation |
| --- | --- | --- | --- |
| Stripe | Repeat an end-grain strip sequence without changing slice orientation. | Supported | Keep as the simplest preset. |
| Checkerboard | Use equal-width alternating species and reverse every other slice. Crosscut width should equal cell width for square checks. | Supported | Keep, but make the preset set or validate square-cell dimensions. |
| Running bond / brick | Use equal-width alternating species and shift every other slice by half a cell. | Supported | Keep and label the half-cell offset in the UI. |
| Third bond | Shift successive slices by 0, one-third, and two-thirds of a cell. | Supported | Add next; it exercises existing `rowOffsets` without new geometry. |
| Chevron / zig-zag | Alternate positive and negative strip angles; alternate slice orientation when a continuous zig-zag is wanted. | Supported with trimming | Split the current Chevron preset into Chevron and Zig-zag variants, and surface side-trim waste. |
| Stepped wave | Apply a repeating ascending and descending slice offset, such as 0, 1/4, 1/2, 3/4, 1/2, 1/4 cell. | Supported | Add as an editable offset preset. Call it stepped, since the geometry is not a true curve. |
| Random mosaic | Use unequal strip widths and a deterministic sequence of slice flips and offsets. | Supported | Add only with a seed so reopening or comparing a design is reproducible. |
| Basket weave | Group contrasting narrow and wide laminations, crosscut in the opposite direction, then rotate and flip selected subassemblies. | Not faithfully supported | Gate on multiple source panels and composite blanks. Do not approximate it with whole-slice offsets. |
| Tumbling blocks / 3D cubes | Build three-tone diamond or rhombus units whose light, medium, and dark faces create the depth illusion. | Not supported | Requires block-level parts, angled/rhombus geometry, and more than one source recipe. |
| Herringbone | Alternate the direction of rectangular units at 90 degrees. | Not supported | Requires block-level orientation rather than whole-slice transforms. |
| Pinwheel / spiral | Rotate repeating units around a center or across a larger repeat tile. | Not supported | Requires a 2D tile/part assembly model and arbitrary placement. |

## Recommended delivery order

1. Add Third bond and Stepped wave using the existing offset array.
2. Separate Chevron and Zig-zag, with validation for angled-strip trimming and closed/crossing strips.
3. Make Random mosaic seeded and persist the seed with the preset parameters.
4. Add preset metadata: name, description, difficulty, minimum species count, dimensional constraints, and required construction capabilities.
5. Implement multiple source panels and composite blanks before offering Basket weave or 3D cube presets.
6. Add a 2D part/tile assembly model before Herringbone, Pinwheel, or Spiral.

## UX and validation notes

- Presets should be editable recipes, not decorative overlays.
- Show a capability badge such as `Two glue-ups`, `Composite blank`, or `Block assembly`.
- When a pattern depends on square cells, couple strip width and crosscut width or show a visible warning.
- Preserve the chosen species when applying a preset; use light, medium, and dark roles for 3D patterns instead of hard-coded species.
- Report final squaring waste for angled designs before presenting cost or finished dimensions.
- Pattern thumbnails should be generated by the same geometry used by the build plan.

## Sources reviewed

- [3D End Grain Cutting Board, Instructables](https://www.instructables.com/3D-End-Grain-Cutting-Board-1/) demonstrates the common three-tone 3D effect and a multi-step build rather than a surface-only graphic.
- [Basket Weave End Grain Cutting Board Tutorial, Matt Muirhead](https://www.muirheadphoto.com/wood/basketplans) offers a dedicated 15-page build tutorial and dimension calculator, evidence that basket weave needs its own dimensional recipe.
- [Making a 3D Basket Weave End Grain Cutting Board, Obsessed Woodworking](https://www.obsessedwoodworking.com/projects/3d-basket-weave-end-grain-cutting-board/) describes three hardwoods, varying strip widths, multiple glue-ups, opposite-direction cuts, and rotated/flipped strips.
- [Basket Weave plans, Evo Woodworks](https://www.evowoodworks.com/products/diy-plans-basic-basket-weave-end-grain-cutting-board) includes size-specific cut lists, part dimensions, cutting/gluing order, and species guidance, reinforcing the need for a recipe and cut-plan model rather than a visual preset alone.

These sources are inspiration and construction references only. SawdustAtlas should implement original parameterized recipes and generated diagrams, not copy paid plan dimensions, text, or artwork.
